# Budget mode (Pro tier)

Цей проєкт працює у «бомж-режимі». При будь-якому розкладі обирай найдешевший шлях виконання завдання.

## Вибір інструменту
- **Перш ніж викликати MCP-tool** — спитай себе: «чи можна це зробити через `Bash` (git, curl, jq, ls), `Read`, `Grep` або `Glob`?» Якщо так — роби саме так. MCP викликай тільки коли альтернативи немає.
- **Не спавни Agent/Explore** для задач, які закриваються 1–3 викликами `Grep`/`Glob`/`Read`. Sub-agent — тільки для справді open-ended досліджень по >3 запитах.
- **Не викликай WebFetch/WebSearch**, якщо користувач явно не попросив свіжу інформацію з інтернету.
- **`Read` тільки потрібні діапазони** (`offset`/`limit`), не читай файли цілком, якщо потрібна одна функція.
- **Уникай `TodoWrite`** для задач у 1–3 кроки.

## Reasoning і відповіді
- Не пиши довгі пояснення й дисклеймери — 1–2 речення підсумку.
- Не коментуй свій внутрішній хід думок у чат.
- Не додавай коментарі в код без явної потреби.
- Не створюй README/доки, якщо не просили.

## Git / побічні дії
- Не роби зайвих `git status`/`git diff` між кроками — тільки коли справді потрібно.
- Не запускай тести/лінтери «про всяк випадок» — тільки коли зміна того вимагає.
